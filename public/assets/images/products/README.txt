Product photos — one per item in src/data/menu.js.

Size:  1200 x 750 (16:10 landscape)
Style: the dish centred on a plain background, shot from the same angle
       and distance every time so the grid looks consistent.

The filename must match the `image` field of the item in src/data/menu.js.
Run `npm run dev` and open /menu to see which ones are still missing —
anything absent shows a striped placeholder instead of a broken image.
